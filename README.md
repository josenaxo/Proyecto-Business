## Purpose

This package contains the W1 report and the analysis supporting it. The report explores two candidate lines of inquiry on overtime among fixed-term (*contrata*) staff of the Servicio de Salud Metropolitano Central (SSMC), using 24 monthly payrolls published under Active Transparency (September 2024 – August 2026).

The report PDF is self-contained. The notebook and data allow the reported results to be verified and reproduced.

## Data source

- **Source:** State Transparency Portal (Portal de Transparencia), Active Transparency of the Servicio de Salud Metropolitano Central (organization code AO006), fixed-term staff payroll (*Personal a contrata*).
- **Link:** https://www.portaltransparencia.cl/PortalPdT/
- **Period:** 24 monthly files, September 2024 – August 2026 (44,777 records).
- **Download date:** September 15, 2026. Published files may change after this date; the files in `data/` are the versions used.
- **Retrieval:** on the portal, search for the Servicio de Salud Metropolitano Central (AO006), open its Active Transparency section, go to the fixed-term staff payroll, select each month from September 2024 to August 2026 and download it as CSV. Each file was saved as `TransparenciaActiva_YYYY-MM.csv`, which is the name pattern the notebook reads.
- **Format:** semicolon-separated, latin-1 encoding.
- **Scope:** fixed-term staff only; it does not include permanent, fee-based or Labor Code staff.

The input files are included in full because they are small. No filtering was applied before loading; all transformations are documented in the notebook.

## Data notes

These are source characteristics, not execution errors. They are explained in Section 2.3 of the report:

- Each row is a contract record, not a person. Results are aggregated per person-month.
- The files contain no national ID number (RUT); people are identified by full name.
- The holiday overtime column has no values in any month.
- The staff category column appears misrecorded in December 2025. That month is excluded from analyses by staff category.
- January 2025 is atypical: dashes in the additional pay column and 99 of the 182 cases above the 40-hour limit.

## Privacy

The input files contain employees' full names, as published under Law 20.285. The notebook outputs and the report present only aggregated counts by staff category and month; no individual is identified.
